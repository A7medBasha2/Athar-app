# نظام المعالجة الذكي لزر وإيماءات الرجوع في أندرويد (Android Back Navigation System)

نظام ملاحة متكامل وعالي الاعتمادية للتعامل مع زر الرجوع العتادي وإيماءات السحب الجانبية في نظام أندرويد (إصدارات 12 و 13 و 14 و 15 و 16)، يمنع الإغلاق الفجائي للتطبيق، ويوفر تسلسلاً هرمياً ذكياً يبدأ بإغلاق النوافذ المنبثقة، ثم الرجوع من الشاشات الفرعية، ثم تتبع سجل التبويبات خطوة بخطوة، وصولاً إلى الشاشة الرئيسية التي تتطلب ضغطتين متتاليتين مع إشعار توست للخروج بأمان.

---

### قرارات المستخدم المؤكدة (Confirmed Decisions)

> [!IMPORTANT]
> تم تأكيد الخيارات التالية استناداً إلى إجابات المستخدم على الأسئلة التوضيحية:
> - [x] **سلوك الخروج عند الشاشة الرئيسية**: ضغطتان متتاليتان خلال ثانيتين مع إشعار توست إسلامي فاخر: *"اضغط مرة أخرى للخروج من أثر"*.
> - [x] **سجل التبويبات (Tab History Stack)**: تتبع كامل لسجل التبويبات التاريخية السابقة (مثال: الرئيسية -> القبلة -> الأذكار -> المصحف)، بحيث يعود المستخدم بالترتيب العكسي خطوة بخطوة حتى بلوغ الرئيسية.
> - [x] **نطاق التنفيذ**: تطبيق برمجي كامل ومباشر في المشروع يجمع بين طبقة الويب وواجهة المستخدم (TypeScript / React / `@capacitor/app`) وطبقة الأندرويد الأصلية (`MainActivity.java` / `AtharNativeBridgeInterface`).

## 1. نظرة عامة والهدف العام (Overview & Core Concept)

### المشكلة الحالية
في تطبيقات الهواتف الهجينة (Capacitor/WebView)، يتصرف زر الرجوع الافتراضي في نظام أندرويد بإحدى طريقتين مزعجتين:
1. إغلاق التطبيق فوراً وإنهاؤه (`finishActivity`) حتى لو كان المستخدم داخل نافذة أذكار، أو يستمع لتلاوة، أو يقرأ سورة.
2. عدم إدراك النوافذ المنبثقة (Modals) والقوائم المنسدلة، مما يؤدي إلى خروج المستخدم من الصفحة بدلاً من إغلاق النافذة المفتوحة أمامه.

### الهدف المنشود
بناء **موزع ملاحة ذكي ذي أولوية هرمية (Priority-Based Back Navigation Stack)** يضمن تجربة سلسة تشابه التطبيقات الأصلية بالكامل (Native UX):
- **المستوى الأول (الأولوية القصوى)**: إغلاق أي نافذة منبثقة أو مشغل صوتي أو حوار معروض.
- **المستوى الثاني**: إغلاق أي شاشة فرعية أو وضع قراءة مفصل (مثل قارئ السور في المصحف أو الأدوات الفرعية في استكشف) والعودة للقائمة الرئيسية للتبويب.
- **المستوى الثالث**: الرجوع خطوة للخلف في سجل التبويبات (`navigationHistoryStack`) وصولاً إلى تبويب "الرئيسية".
- **المستوى الرابع (جذر التطبيق)**: عند التواجد في الشاشة الرئيسية وخلو السجل، تفعيل مؤقت الأمان لمدة ثانيتين؛ الضغطة الأولى تظهر إشعار توست هادئ، والضغطة الثانية تنفذ الخروج الآمن أو تصغير التطبيق.

## 3. التصميم البصري لإشعار الخروج (Visual Design & Toast Feedback)

- **الموقع**: شريط عائم سفلي مرتفع عن شريط التبويبات السفلي بمسافة آمنة (`bottom-20 z-50`).
- **الهوية البصرية**: تدرج داكن فخم منسجم مع تصميم أثر (`bg-[#1A160F] border border-[#C8A24A]/40 text-[#F3E5AB]`).
- **الأيقونة والنص**: أيقونة هادئة مع نص عربي وقور: `"اضغط مرة أخرى للخروج من أثر"` بخط الرقعة/النسخ المتزن.
- **الحركة**: ظهور واختفاء انسيابي عبر أنيميشن تدرج شفافية وارتفاع لطيف (`animate-in fade-in slide-in-from-bottom-2 duration-200`).

## 4. المكونات التقنية وخطوات التنفيذ (Technical Implementation)

### 1. تثبيت حزمة `@capacitor/app`
- تثبيت حزمة `@capacitor/app` الرسمية للتواصل مع دورة حياة أندرويد واستقبال حدث `backButton`.
- تسجيل مستمع الحدث عالمياً عبر `App.addListener('backButton', callback)`.

### 2. بناء خدمة الملاحة وإدارة الرجوع (`src/services/backNavigationService.ts`)
إنشاء خدمة مركزية لإدارة مكدس التراجع (Back Handler Stack) مع دعم التسجيل الديناميكي للأولويات:
- **دعم تسجيل المعالجات المؤقتة (Dynamic Handlers)**: يتيح لأي نافذة منبثقة (مثل أذكار المساء، أو حاسبة الزكاة، أو نافذة الإنجازات) تسجيل وظيفة إغلاق خاصة بها تلتقط الضغطة وتستهلكها فوراً (`event.consumed = true`).
- **تتبع سجل التبويبات (Tab History Stack)**: مصفوفة تسجل تسلسل التبويبات المزارة مع منع تكرار نفس التبويب المتتالي، والرجوع التدريجي.

### 3. ربط كافة النوافذ والشاشات الفرعية في `src/App.tsx`
- ربط النوافذ التالية لتغلق تلقائياً عند ضغط زر الرجوع بالترتيب:
  1. `globalShareCardPayload` (مشاركة البطاقات)
  2. `isUpdateModalOpen` (نافذة التحديث)
  3. `isAlarmModalOpen` (تنبيه مواقيت الصلاة)
  4. `isAchievementsOpen` (سجل الإنجازات)
  5. `isSakinaOpen` (سكينة القلوب)
  6. `isZakatOpen` (حاسبة الزكاة)
  7. `isTasbihOpen` (المسبحة الإلكترونية)
  8. `isVoiceAssistantOpen` (المساعد الصوتي)
  9. `isCodeInspectorOpen` (فاحص الكود)
  10. `isOnboardingOpen` (التهيئة الأولى)
  11. `readingSurahNumber` (وضع قراءة السورة في المصحف)
  12. `exploreSubView` (أقسام استكشف الفرعية)
- معالجة الضغط المزدوج عند التواجد في تبويب `home` مع إظهار التوست الهادئ واستدعاء `App.exitApp()` أو `AtharNative.exitApp()`.

### 4. ترقية كود أندرويد الأصلي (`MainActivity.java`)
- إضافة أسلوب `exitApp()` و `minimizeApp()` داخل `AtharNativeBridgeInterface` لاستخدامه كمسار استدعاء أصلي سريع وموثوق:
  ```java
  @JavascriptInterface
  public void exitApp() {
      runOnUiThread(() -> {
          finishAffinity();
          System.exit(0);
      });
  }
  
  @JavascriptInterface
  public void minimizeApp() {
      runOnUiThread(() -> {
          moveTaskToBack(true);
      });
  }
  ```
- التأكد من توافق `MainActivity` مع معايير أندرويد الحديثة (Android 13/14/15/16 Predictive Back Gesture) دون أي تعارض مع شريط التصفح السفلي.

## 5. خطة التحقق والاختبار (Verification Plan)

1. **التحقق من تثبيت الحزم والبناء**:
   - تشغيل `npm run build` للتأكد من نجاح التجميع مع الحزمة الجديدة.
   - فحص الأنواع مع `tsc --noEmit`.
2. **اختبار هرمية الرجوع (Scenario Testing)**:
   - *سيناريو 1 (النافذة المنبثقة)*: فتح نافذة الأذكار ثم ضغط زر الرجوع -> التأكد من إغلاق النافذة وبقاء الشاشة الحالية.
   - *سيناريو 2 (شاشة فرعية)*: الانتقال للمصحف وفتح سورة الكهف ثم ضغط زر الرجوع -> العودة لقائمة سور المصحف.
   - *سيناريو 3 (سجل التبويبات)*: التنقل من الرئيسية -> المصحف -> القبلة -> ضغط الرجوع -> العودة للمصحف ثم ضغط الرجوع -> العودة للرئيسية.
   - *سيناريو 4 (الخروج المزدوج)*: التواجد بالرئيسية وضغط الرجوع -> ظهور توست التنبيه؛ ضغطة ثانية سريعة -> إغلاق التطبيق.
