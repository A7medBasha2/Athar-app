# خطة التطوير والتحديثات الدقيقة لتطبيق «أثر»

خطة معمارية وتنفيذية شاملة لتحقيق التزامن الصوتي التام في كارت «ردد مع المؤذن»، وضبط منطق تسجيل الصلوات في شجرة الأثر، والربط المباشر لأصوات المؤذنين، وضبط نمط التكبيرتين وتخصيص تنبيهات الإقامة لكل صلاة مع تنظيف شاشة الإعدادات.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد التفضيلات التالية بناءً على إجابات الأسئلة التوضيحية:
> - **توقيت نمط التكبيرتين**: اعتماد التوقيت الصوتي الدقيق لكل مؤذن (نحو 14 إلى 22 ثانية بحسب تسجيل المؤذن المختار)، مع القطع الصوتي التلقائي فور إتمام التكبيرة الثانية.
> - **عرض كارت «ردد مع المؤذن»**: إبراز جملة المؤذن الحالية مع إظهار جواب الترديد النبوي المستحب (مثل: «لَا حَوْلَ وَلَا قُوَّةَ إِلَّا بِاللهِ» عند الحيعلتين) بتصميم إسلامي فاخر وواضح.

- **القرار المعتمد 1 (ربط الصلاة والمنع المبكر)**: يُعطّل زر تسجيل الصلاة تماماً (`disabled` و`opacity-50`) إذا لم يحن موعد الأذان الشرعي لتلك الصلاة بعد، ويُقفل الزر بمجرد الضغط عليه لمنع التراجع، مع تحديث شجرة الأثر وقسم الصلاة بصورة فورية متزامنة عبر `StorageService` وCustom Events.
- **القرار المعتمد 2 (تحديث صوت المؤذن الفوري)**: عند اختيار أي مؤذن في شاشة الإعدادات، يتم تحديث الإعداد العام وإعداد الصلوات المفروضة مباشرة، وإذا كانت شاشة الأذان تعمل أو يُجرى اختبارها يتم تحديث مصدر الصوت ومحاكاته فورياً دون إعادة تعيين غير مرغوبة.
- **القرار المعتمد 3 (تنظيف الإعدادات)**: إزالة حاوية «أذونات شاشة الأذان على أجهزة أندرويد» بالكامل من قسم التنبيهات في صفحة الإعدادات لتنظيف الواجهة وتجنب الإرباك.

---

## 1. Overview & Core Concept

تتكامل هذه التحديثات الست لترقية تجربة الأذان والصلاة في تطبيق «أثر» إلى أعلى درجات الدقة والراحة:
1. **المزامنة الصوتية الحية لترديد الأذان**: قراءة موضع التشغيل الفعلي (`AudioService.getLiveCurrentTime()`) ومطابقته مع مصفوفة الفواصل الزمنية الدقيقة لكل جملة لكل مؤذن، ليظهر النص وجواب الترديد متزامناً مع صوت الأذان الفعلي.
2. **انضباط شجرة الأثر وقسم الصلاة**: منع تسجيل أي صلاة قبل أوانها (تعطيل كامل للزر) وقفل الزر نهائياً بعد التسجيل لمنع التراجع، مع التحديث اللحظي للواجهتين.
3. **الربط المباشر للمؤذن بالشاشة الملكية**: تحديث مباشر لصوت المؤذن في شاشة الأذان الملكية عند تغييره من الإعدادات.
4. **نمط التكبيرتين التلقائي**: التوقف الصوتي الفوري بعد إتمام التكبيرتين وفق المدة المحددة لكل تسجيل مؤذن، ثم الانتقال التلقائي لدعاء ما بعد الأذان.
5. **تنظيف شاشة الإعدادات**: التخلص من قائمة أذونات الأذان غير الضرورية داخل صفحة الإعدادات.
6. **اعتماد تنبيهات الإقامة المخصصة**: ربط مواقيت الإقامة بالدقائق المحددة لكل صلاة (الفجر، الظهر، العصر، المغرب، العشاء) في محرك التنبيهات وشريط الأنشطة الحية.

## 2. User Experience & Visual Design

### التسلسل التفاعلي للمستخدم (User Flows)
1. **أثناء رفع الأذان**:
   - تفتح شاشة الأذان الملكية بصور الحرمين الشريفين والمسجد الأقصى.
   - كارت **«ردد مع المؤذن»** يبرز عبارة الأذان الحالية بحجم خط قرآني ذهبي واضح، وتحتها يظهر فوراً الجواب المستحب (مثال: جملة «حَيَّ عَلَى الصَّلَاةِ» يرافقها جواب الترديد «لَا حَوْلَ وَلَا قُوَّةَ إِلَّا بِاللهِ»).
   - في نمط «تكبيرتان فقط»، يصمت الصوت تلقائياً بعد التكبيرة الثانية ويتحول الكارت إلى دعاء ما بعد الأذان.
   - زر **«سجّل الصلاة في شجرة الأثر»** مفعل لأن وقت الصلاة قد حان، وبمجرد نقره يتحول إلى حالة التأكيد الخضراء («تم تسجيل صلاة الظهر في شجرة الأثر ✓») ويُقفل الزر نهائياً.
2. **في قسم الصلوات وشجرة الأثر**:
   - الصلوات التي لم يحن موعدها بعد: تظهر أزرارها معطلة تماماً بمظهر غير نشط (`opacity-50 cursor-not-allowed`) مع أيقونة قفل/ساعة هادئة تمنع النقر المبكر.
   - الصلوات المكتملة: تظل مقفلة باللون الذهبي/الأخضر مع إشارة صح ولا تقبل الإلغاء.
3. **في شاشة الإعدادات**:
   - قسم التنبيهات نظيف وموجز وخالٍ من قائمة الأذونات المزعجة.
   - عند النقر على أي مؤذن، يتغير فوراً وينعكس على الشاشة الملكية والتنبيهات.
   - إعدادات مواقيت الإقامة تتيح ضبط كل صلاة بدقائقها الخاصة وتُحفظ وتُفعّل فوراً.

## 3. Key Technical Architecture & Implementation Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Athar State & Storage                           │
│   • AppSettings (adhanVoice, prayersAdhanConfig, iqamahSettings)       │
│   • PrayerAchievementsState (todayPrayers logged state)                │
└──────────────────┬─────────────────────────────────┬───────────────────┘
                   │                                 │
                   ▼                                 ▼
┌──────────────────────────────────────┐  ┌──────────────────────────────┐
│          Audio & Reminders           │  │      UI & Views Layer        │
│  • AudioService:                     │  │  • AdhanRingingModal:         │
│    - playAdhan with clipOptions      │  │    - Live phrase sync card   │
│    - takbeerEndTime exact cut        │  │    - Dua & disabled log btn  │
│    - getLiveCurrentTime()            │  │  • ImpactTree & PrayersView: │
│  • ReminderEngine:                   │  │    - Disabled before arrival │
│    - Per-prayer iqamah offsets check │  │    - Permanent lock on done  │
│    - Real-time voice sync            │  │  • SettingsView:             │
│                                      │  │    - Cleaned notifications   │
└──────────────────────────────────────┘  └──────────────────────────────┘
```

### تفاصيل التعديلات البرمجية في الملفات المعنية:

1. **`src/services/audioService.ts`**:
   - تمرير `clipOptions` (الذي يحتوي على `endTime: target.takbeerEndTime`) إلى دالة `playUrl(target.localUrl, ...)` المفقودة حالياً لضمان توقف الصوت تلقائياً عند اختيار نمط «تكبيرتان فقط».
   - ضبط قيم `takbeerEndTime` الدقيقة لكل مؤذن (Alafasy: 22.8s, Fajr: 18.4s, Makkah: 21.3s, Madinah: 37.3s, Alaqsa: 24.1s).
   - توفير مصفوفة الجداول الزمنية لكل جملة في الأذان (`ADHAN_PHRASE_TIMELINES`) لكل صوت.

2. **`src/components/AdhanRingingModal.tsx`**:
   - تحديث دورة مراقبة التزامن عبر `AudioService.getLiveCurrentTime()` كل 250 مللي ثانية، ومطابقة الثانية الحالية مع مواعيد الجمل الصحيحة بدلاً من التقسيم التقريبي القديم (`Math.floor(elapsed / 9)`).
   - إظهار كارت الترديد الثنائي: نص المؤذن الحالي بالخط القرآني الكبير + جواب الترديد المستحب.
   - عند تغيير المؤذن من الإعدادات أو إرسال حدث التحديث، يتم استلام الصوت الجديد وتحديث شاشة الأذان فورياً.
   - تعطيل زر تسجيل الصلاة إذا لم يحن موعدها، وقفله نهائياً بمجرد التسجيل.

3. **`src/components/ImpactTree.tsx` و `src/views/PrayersView.tsx`**:
   - تفعيل خاصية `disabled={prayer.done || !arrival.arrived}` مع نمط بصري واضح يمنع النقر المبكر.
   - قفل أزرار الصلوات المنجزة نهائياً ومنع إلغاء تسجيلها.
   - ربط وتوحيد التحديث بين قسم الصلوات وشجرة الأثر باستخدام `StorageService` وحدث `athar_prayers_updated`.

4. **`src/views/SettingsView.tsx`**:
   - حذف قسم «أذونات شاشة الأذان على أجهزة أندرويد» بالكامل من قسم التنبيهات.
   - عند تغيير المؤذن `adhanVoice`، تحديث أصوات الصلوات في `prayersAdhanConfig` وإشعار `ReminderEngine` ليتم تطبيقه فوراً على الشاشة الملكية.
   - ربط إعدادات دقائق الإقامة المخصصة لكل صلاة بالـ `ReminderEngine` وتأكيد انعكاسها في التنبيهات وإشعار الإقامة الصوتي.

5. **`src/services/reminderService.ts`**:
   - ضمان اعتماد `iqamahSettings.offsets` المخصصة لكل صلاة في دورة الفحص الدوري `checkPrayerTimes()`.
   - الاستجابة المباشرة لتغيير صوت المؤذن وتحديث الأذان النشط إن وجد.

## 4. Verification & Testing Plan

1. **اختبار مزامنة الترديد**: تشغيل معاينة الأذان والتأكد من انتقال العبارة وجواب الترديد بدقة تامة مع نبرة المؤذن.
2. **اختبار نمط التكبيرتين**: تفعيل خيار «تكبيرتان فقط» والتأكد من صمت الصوت تلقائياً بعد التكبيرة الثانية وظهور دعاء ما بعد الأذان.
3. **اختبار منع التسجيل المبكر والقفل**: فحص أزرار الصلوات قبل وقتها والتأكد من أنها معطلة ولا تستجيب، ثم تسجيل صلاة حان وقتها والتأكد من قفل الزر ومنع التراجع وتحديث الشجرة وقسم الصلاة معاً.
4. **اختبار تغيير المؤذن**: تغيير المؤذن من الإعدادات والتأكد من انطباقه الفوري على الأذان.
5. **اختبار مواقيت الإقامة**: فحص عمل تنبيه الإقامة وفق الدقائق المخصصة لكل صلاة.
6. **فحص سلامة البناء**: تشغيل `tsc --noEmit` و `vite build` والتأكد من خلو المشروع من أية أخطاء.
