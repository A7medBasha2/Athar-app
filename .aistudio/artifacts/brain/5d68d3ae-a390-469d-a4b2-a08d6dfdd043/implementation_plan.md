# خطة تطوير نظام التنبيهات والأذكار الملكي الفاخر لتطبيق «أثر»

خطة معمارية وبرمجية شاملة لإلغاء تبويب الأذكار والسنن القديم، وتشييد **نظام التنبيهات والأذكار الملكي** بأعلى درجات الأولوية والخلفية الصوتية الذكية، مع هندسة طابور تنبيهات متتابع (Queue System)، حفظ الأولوية التامة للأذان، وتقديم بطاقة ملكية منبثقة عائمة بتأثير الزجاج الذهبي الفاخر.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> تم تأكيد تفضيلات التصميم والتحكم بناءً على إجابات الأسئلة التوضيحية:
> - **شكل التنبيه الملكي**: بطاقة ملكية منبثقة عائمة مع تأثير الزجاج الذهبي المضيء والخطوط القرآنية الفاخرة (`Luxury Floating Gold Glass Card`).
> - **أزرار الاختبار**: تخصيص زر تجربة مستقل لكل تنبيه من التنبيهات الأربعة داخل تبويب «الإشعارات» في الإعدادات (مع مؤقت 5 ثوانٍ تنازلي أنيق).
> - **إلغاء التبويب القديم**: حذف تبويب «الأذكار والسنن» بالكامل وإلغاؤه من صفحة الإعدادات لتجنب أي تداخل مع نظام الإشعارات الملكي.

---

## 1. Overview & Core Concept

1. **إلغاء التبويب القديم وتأسيس تبويب "الإشعارات"**:
   - إزالة تبويب «الأذكار والسنن» المعزول من الإعدادات.
   - تدشين تبويب ملكي موحد باسم **«الإشعارات»** يجمع ضبط الأذان ومواقيت الإقامة والتنبيهات الأربعة الكبرى وفترات الهدوء وأزرار المعاينة.

2. **التنبيهات الأربعة الملكية وأصواتها وأزرارها**:
   - **التنبيه الأول (اقرأ ولو آية في اليوم)**:
     - اختيار آية كريمة عشوائياً من المصحف برقم السورة واسمها والآية.
     - الصوت: «وَرَتِّلِ الْقُرْآنَ تَرْتِيلًا» (`/audio/quran_sample.mp3`).
     - أزرار: إيقاف التنبيه · كتم/تشغيل الصوت · زر «فتح الآية» للانتقال المباشر للآية في المصحف.
   - **التنبيه الثاني (ذكر الله والصلاة على النبي ﷺ)**:
     - صيغة صلاة نبوية أو تسبيح مأثور مع الفضل الإيماني.
     - الصوت: نداء الصلاة على النبي المبارك (`/audio/salawat.mp3`).
     - أزرار: إيقاف التنبيه · كتم/تشغيل الصوت · زر «فتح الأذكار» للانتقال لصفحة الأذكار.
   - **التنبيه الثالث (الورد اليومي)**:
     - تذكير حثيث بقراءة الورد وتثبيت الجزء والصفحات المقررة.
     - الصوت: تلاوة خاشعة لنداء الترتيل (`/audio/wird.mp3`).
     - أزرار: إيقاف التنبيه · كتم/تشغيل الصوت · زر «فتح الورد القرآني» المخصص.
   - **التنبيه الرابع (بر الوالدين)**:
     - تذكير بالدعاء وبر الوالدين وطاعتهما.
     - الصوت: «وَقُل رَّبِّ ارْحَمْهُمَا كَمَا رَبَّيَانِي صَغِيرًا» (`/audio/parents.mp3`).
     - التحكم الزمني: إمكانية اختيار تكرار التنبيه (كل 30 دقيقة، كل 1 ساعة، كل ساعتين، كل 3 ساعات، كل 6 ساعات، كل 12 ساعة، أو مرة يومياً).
     - أزرار: إيقاف التنبيه · كتم/تشغيل الصوت · زر «فتح بر الوالدين» للانتقال لميثاق وبر الوالدين.

3. **الضوابط التقنية والأولويات الصارمة**:
   - **الأولوية المطلقة للأذان**: عند رفع الأذان أو عند اقتراب وقته (15 ثانية أو أقل)، يتوقف أو يتأجل أي تنبيه تلقائياً لما بعد الأذان والدعاء، ما لم يكن التنبيه قصيراً جداً.
   - **طابور التنبيهات (Queue System)**: محرك طابور متتابع يمنع تشغيل صوتين معاً أو فتح بطاقتين فوق بعضهما؛ حيث تُعرض التنبيهات واحداً تلو الآخر بسلاسة.
   - **أنماط التنبيه الثلاثة لكل تنبيه**:
     1. إشعار مرئي فقط (صامت).
     2. إشعار مع زر تشغيل الصوت عند الطلب.
     3. إشعار بصوت تلقائي فوري.
   - **فترة الهدوء (وضع عدم الإزعاج)**: ضبط ساعات النوم (Start/End Time) لتعليق التنبيهات الصوتية المزعجة تلقائياً.

## 2. User Experience & Visual Design

### التصميم المعماري للبطاقة الملكية (Luxury Floating Gold Glass Card)
- **الحاوية**: بطاقة عائمة متمركزة فوق المحتوى بخلفية داكنة خافتة وضباب زجاجي (`bg-black/75 backdrop-blur-md`).
- **الإطار والسطح**: تدرج فاخر من الأسود الإمبراطوري (`#120E09`) مع إطار ذهبي رقيق ونبض نوري خافت (`border border-[#E6C66E]/50 shadow-[0_25px_60px_rgba(0,0,0,0.95),0_0_25px_rgba(230,198,110,0.2)] rounded-3xl`).
- **المنطقة العلوية**: شعار «أثر» الملكي مع شارة فئة التنبيه وتوقيته.
- **المنطقة المركزية**: نص الآية أو الذكر بالخط القرآني (Amiri/Scheherazade) مذهب التشكيل والظلال.
- **أزرار التحكم السفلية**:
  - صف الأزرار السريعة: كتم/تشغيل الصوت لايف، وإيقاف التنبيه.
  - الزر الرئيسي الفاخر: الانتقال المباشر لوجهة التنبيه (المصحف / الأذكار / الورد / بر الوالدين).

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Storage & Settings Layer                        │

│   • Persistent state in storageService                                 │
└──────────────────┬─────────────────────────────────┬───────────────────┘
                   │                                 │
                   ▼                                 ▼
┌──────────────────────────────────────┐  ┌──────────────────────────────┐
│       Royal Notification Engine      │  │        UI Overlays           │
│  • RoyalReminderEngine:              │  │  • RoyalNotificationSheet:   │
│    - Priority Queue Management       │  │    - Luxury Gold Glass card  │
│    - Adhan-preemption guard (15s)    │  │    - Play/Mute & dismiss     │
│    - Quiet Hours evaluation          │  │    - Deep-link action button │
│    - 5-second countdown test handler │  │  • SettingsView:             │
│  • AudioService (tone triggers)      │  │    - Unified "الإشعارات" tab │
└──────────────────────────────────────┘  └──────────────────────────────┘
```

### خطة الملفات والتعديلات البرمجية:

1. **`src/types/index.ts`**:
   - تعريف بنية `RoyalNotificationMode` (`'banner_only' | 'banner_with_play' | 'auto_sound'`).
   - تعريف كائن `RoyalNotificationItem` والبيانات المصاحبة للآية والأذكار والورد وبر الوالدين.
   - تحديث واجهة `AppSettings` بإعدادات التنبيهات الأربعة وساعات الهدوء.

2. **`src/services/royalReminderEngine.ts` (جديد)**:
   - محرك مركزي لطابور التنبيهات (Queue System).
   - التحقق اللحظي من الأذان (إذا كان الأذان يعمل أو متبقياً عليه $\le 15$ ثانية، يُؤجل التنبيه).
   - فحص ساعات الهدوء (Quiet Hours).
   - إدارة عداد الـ 5 ثوانٍ للاختبار والمعاينة المستقلة لكل تنبيه.

3. **`src/components/RoyalNotificationSheet.tsx` (جديد)**:
   - مكون البطاقة المنبثقة العائمة بزجاج الذهب الإمبراطوري.
   - يدعم عرض الآية العشوائية المحددة، أو نص الصلاة على النبي، أو الورد، أو بر الوالدين.
   - أزرار التحكم الصوتي المباشر والانتقال السلس إلى الوجهة المستهدفة.

4. **`src/views/SettingsView.tsx`**:
   - إزالة تبويب «الأذكار والسنن» القديم تماماً.
   - تدشين تبويب **«الإشعارات»** الموحد المتكامل:
     - قسم الأذان والإقامة.
     - أقسام التنبيهات الأربعة: أنماط التنبيه، المواعيد، تكرار بر الوالدين (من كل 30 دقيقة إلى يومياً).
     - ساعات الهدوء (وضع عدم الإزعاج).
     - أزرار اختبار مستقلة لكل تنبيه مع عداد تنازلي 5 ثوانٍ.

5. **`src/App.tsx`**:
   - تضمين `RoyalNotificationSheet` كطبقة عليا مدعومة بأحداث التنقل السلس لوجهات المصحف، الأذكار، الورد القرآني، وبر الوالدين في سكينة وحقوق.

## 4. Verification & Testing Protocol

1. **فحص حظر التداخل وأولوية الأذان**: محاكاة تنبيه أثناء الأذان والتأكد من تأجيله لطابور الانتظار.
2. **فحص طابور التتابع (Queue)**: إطلاق تنبيهين في وقت متقارب والتأكد من ظهورهما تباعاً دون تداخل صوتي.
3. **فحص الأنماط الثلاثة**: اختبار (إشعار فقط، إشعار بزر تشغيل، صوت تلقائي).
4. **فحص أزرار الاختبار (5 ثوانٍ)**: النقر على زر تجربة كل تنبيه والتأكد من عمل العداد التنازلي وظهور البطاقة الملكية الفاخرة.
5. **فحص أزرار الانتقال المباشر**: التأكد من أن "فتح الآية" ينقل للمصحف والآية المحددة، "فتح الأذكار" ينقل للأذكار، "فتح الورد" يفتح الورد، و"فتح بر الوالدين" يفتح بطاقة بر الوالدين.
6. **التجميع وخلو الأخطاء**: التحقق عبر `tsc --noEmit` و `vite build`.
