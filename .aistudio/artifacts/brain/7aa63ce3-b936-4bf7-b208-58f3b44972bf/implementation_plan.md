# خطة تطبيق الصور الديناميكية للمساجد في كارت الصلاة القادمة

خطة هندسية لتحديث مربع الصلاة القادمة في الصفحة الرئيسية ليعرض صوراً فوتوغرافية فائقة الدقة للمساجد الثلاثة المقدسة (المسجد الحرام، المسجد النبوي، والمسجد الأقصى) تتغير ديناميكياً مع تغير الصلاة القادمة وأوقات الإضاءة الطبيعية لليوم، مع الحفاظ الصارم على أبعاد وتنسيق وتصميم الكارت الملكي.

---

## القرارات المؤكدة من مرحلة الاستيضاح (Confirmed Decisions)

> [!IMPORTANT]
> - **أساس التغيير الديناميكي**: ربط صورة المسجد بـ **الصلاة القادمة المرتقبة** (`nextPrayer.id`) لتتطابق بصرياً وروحانياً مع هوية وموعد الصلاة القادمة (الفجر، الشروق، الظهر، العصر، المغرب، العشاء).
> - **الطابع المعماري للمساجد**: اعتماد **المساجد الثلاثة المقدسة** (المسجد الحرام بمكة، المسجد النبوي بالمدينة المنورة، والمسجد الأقصى المبارك بالقدس الشريف) مع التوافق التام مع إضاءة وقت اليوم.

---

## 1. جدول تطابق المساجد وأوقات الإضاءة (Dynamic Mapping)

| الصلاة القادمة | المسجد المقدس المعتمد | وقت الإضاءة والجو الروحي | الصورة المعتمدة |
| :--- | :--- | :--- | :--- |
| **الفجر (Fajr)** | **المسجد الحرام - الكعبة المشرفة** | سحر الفجر، سكون الليل ونسيم الفجر الأزرق مع إضاءة الحرم الذهبية | `adhan_fajr_dawn_kaaba` |
| **الشروق (Sunrise)** | **المآذن الإسلامية ومسجد قباء** | شروق الشمس الذهبي، أول أشعة الصباح وأفق السماء الصافي | `adhan_golden_minaret_sky` |
| **الظهر (Dhuhr)** | **المسجد النبوي الشريف - المدينة** | ضياء الظهيرة الساطع، ساحات الحرم النبوي والمظلات والرخام الأبيض | `adhan_dhuhr_madinah_sunlight` |
| **العصر (Asr)** | **المسجد الأقصى المبارك - القدس** | الساعة الذهبية (Golden Hour) وانعكاس أشعة العصر الدافئة على القبة الذهبية | `adhan_asr_aqsa_golden_hour` |
| **المغرب (Maghrib)** | **رحاب المسجد الحرام والمآذن** | شفق الغروب البنفسجي والبرتقالي المهيب وأذان المغرب | `adhan_maghrib_sunset_minarets` |
| **العشاء (Isha)** | **الكعبة المشرفة والحرم المكي** | ليل الحرم الساكن، السماء المرصعة بالنجوم وأضواء الطواف الذهبية | `adhan_isha_night_sanctuary` |

## 2. المعمارية البرمجية وضمان الحفاظ على التنسيق (Layout Integrity)

```
┌────────────────────────────────────────────────────────────────────────┐
│                   NEXT PRAYER CARD DYNAMIC MOSQUE                      │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│   prayerData.nextPrayer.id                                             │
│      ├── 'fajr'    ──> 🕋 Kaaba Dawn Sanctuary                         │
│      ├── 'sunrise' ──> ☀️ Golden Sunrise Minarets                      │
│      ├── 'dhuhr'   ──> 🕌 Madinah Sunlight courtyards                  │
│      ├── 'asr'     ──> 🕌 Al-Aqsa Golden Hour                          │
│      ├── 'maghrib' ──> 🌅 Sunset Dusk Minarets                         │
│      └── 'isha'    ──> ✨ Kaaba Nocturnal Glow                         │
│                                                                        │
│   Preserved UI Shell:                                                  │
│   - Same height (h-44 w-full), rounded-3xl, golden border #C8A24A/50   │
│   - Same dual measured gradient scrims (bottom & left) for 100%        │
│     typography contrast                                                │
│   - Same live countdown component & 5-prayer horizontal strip          │
│   - Smooth cross-fade transition on image update                       │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

1. **التحميل المسبق التلقائي (Preloading)**:
   - تضمين روابط الصور الست في `ImagePreloadService` أو في ذاكرة المتصفح بحيث لا يحدث أي وميض أسود أو تأخير عند التنقل بين الصلوات.
2. **ثبات واستقرار التنسيق (Zero Layout Shift)**:
   - الحفاظ على نفس الحاوية `relative h-44 w-full overflow-hidden rounded-3xl`.
   - الحفاظ على تدرجات التعتيم الملكية (`bg-gradient-to-t` و `bg-gradient-to-l`) لضمان وضوح النصوص والأرقام والعداد بدقة تامة.
   - الحفاظ على مكون العداد المنفصل `HomeNextPrayerCountdown` وشريط التقدم وشريط الصلوات الخمس السفلي دون أي مساس بتصميمها أو ألوانها.

## 3. خطة التنفيذ التفصيلية (Step-by-Step Implementation)

### الخطوة الأولى: بناء مصفوفة الصور الديناميكية للمساجد
- استيراد الصور المخصصة عالية الدقة في `HomeView.tsx` أو إنشاء خدمة مساعدة مخصصة:
  - `adhan_fajr_dawn_kaaba`
  - `adhan_golden_minaret_sky`
  - `adhan_dhuhr_madinah_sunlight`
  - `adhan_asr_aqsa_golden_hour`
  - `adhan_maghrib_sunset_minarets`
  - `adhan_isha_night_sanctuary`
- إنشاء دالة مساعدة نقية `getPrayerMosqueScene(nextPrayerId?: string)` تعيد رابط الصورة واسم المسجد ووصف الإضاءة.

### الخطوة الثانية: تطبيق الصورة الديناميكية في كارت الصلاة بـ `HomeView.tsx`
- استبدال الرابط الثابت `LUXURY_IMAGES.sunsetMosqueBanner` بالصورة المستخرجة من دالة المطابقة الديناميكية.
- إضافة مفتاح `key={mosqueScene.src}` وتأثير حركي ناعم `transition-all duration-700 animate-fadeIn` لضمان انتقال تدريجي راقٍ عند تغير الصلاة.
- الحفاظ على النص البديل `alt={mosqueScene.title}` لتعزيز إمكانية الوصول ومعايير التصميم.

### الخطوة الثالثة: التحقق والتجميع
- تشغيل `compile_applet` للتأكد من نجاح التجميع دون أخطاء.
- تشغيل `lint_applet` للتحقق من سلامة الأنماط والأنواع.
- التحقق من عمل البطاقة في كافة الصلوات وظهور الصورة المناسبة لكل وقت.
