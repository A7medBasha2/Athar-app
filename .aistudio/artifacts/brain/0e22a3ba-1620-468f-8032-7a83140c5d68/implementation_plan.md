# خطة تطوير تطبيق أثر (ATHAR) — المميزات الذكية للقرآن والبطاقات الدعوية المصورة

تهدف هذه الخطة إلى إضافة حزمة متكاملة من المميزات التي اخترتها للارتقاء بتجربة الاستماع والحفظ والتدبر ومشاركة الخير في تطبيق **"أثر"**، مع الحفاظ على الهوية البصرية الإسلامية الفاخرة وسلاسة الواجهة.

---

## القرارات المعتمدة بناءً على اختياراتك

> [!IMPORTANT]
> تم بناء هذه الخطة وفق تفضيلاتك المحددة في الأسئلة السابقة:

- **١. مؤقت النوم الذكي مع الخفض التدريجي للصوت (Smart Sleep Timer with Audio Fade-Out)**: إمكانية ضبط إيقاف تلقائي لتلاوة القرآن الكريم أو الأذكار بعد (١٥، ٣٠، ٤٥، ٦٠ دقيقة، أو عند انتهاء السورة الحالية) مع خفض تدريجي وهادئ للصوت في آخر ٣٠ ثانية قبل الإيقاف لراحة النائم.
- **٢. تكرار الآيات للحفظ والتدبر + البحث النصي الشامل داخل آيات القرآن**: إمكانية البحث عن أي كلمة أو جملة داخل آيات المصحف الشريف والانتقال الفوري للآية، بالإضافة إلى خيار تكرار الآية (٣ مرات، ٥ مرات، ١٠ مرات، أو تكرار مفتوح) داخل قارئ السورة لتسهيل الحفظ.
- **٣. مشاركة الآية والحديث كبطاقة مصورة أنيقة (Visual Islamic Share Card Studio)**: تصميم وتوليد بطاقة دعوية مصورة عالية الدقة (PNG) بخلفية من صور الكعبة المشرفة أو المسجد النبوي أو الزخارف الإسلامية الذهبية، لتحميلها أو مشاركتها مباشرة عبر واتساب وتطبيقات التواصل.
- **٤. تنظيم الواجهة والوصول السريع**: إضافة **بطاقة موحدة أنيقة في الشاشة الرئيسية** للوصول السريع لهذه المميزات، مع إتاحة فتحها مباشرة من داخل مشغل القرآن، الأذكار، ومواقيت الصلاة دون تشتيت أو ازدحام.

---

## ١. نظرة عامة وقيمة المميزات الجديدة

- **ماذا تقدم للمستخدم؟**
  1. **الاستماع الليلي المريح**: يستطيع المستخدم تشغيل القرآن أو أذكار المساء قبل النوم وضبط مؤقت النوم ليقوم التطبيق بخفض الصوت تدريجياً ثم إيقافه تلقائياً.
  2. **البحث القرآني وتكرار الحفظ**: الوصول لأي آية في ثوانٍ بمجرد كتابة كلمة منها، وتفعيل تكرار الآية أثناء الاستماع لتثبيت الحفظ.
  3. **نشر الخير بتصميم احترافي**: تحويل "النفحة القرآنية اليومية" أو "الحديث النبوي الشريف" أو "الأذكار" إلى بطاقة مصورة فاخرة تحمل اسم السورة أو الراوي مع التفسير أو المعنى المختصر.

---

## ٢. تجربة المستخدم والتصميم البصري (UX & Visual Design)

### أ. خطوات الاستخدام (User Flows)
1. **من الشاشة الرئيسية (Home)**:
   - بطاقة موحدة أنيقة بعنوان **"واحة التدبر والمشاركة"** تتيح بضغطة واحدة: (البحث في آيات القرآن · مؤقت النوم الصوتي · تصميم بطاقة دعوية مصورة).
   - في بطاقة **"نفحة قرآنية يومية"** وبطاقة **"نفحة نبوية شريفة"**: زر **"مشاركة كبطاقة مصورة"** يفتح معاينة فورية للبطاقة مع إمكانية تغيير الخلفية (الكعبة المشرفة، المسجد النبوي، محراب ذهبي، ليل هادئ) ثم حفظ الصورة أو مشاركتها.
2. **في قسم القرآن الكريم وقارئ المصحف (Quran & Reader)**:
   - شريط بحث مزدوج يتيح التبديل بين **"بحث باسم السورة"** و**"بحث في نص الآيات"** مع عرض نتائج الآيات المطابقة، اسم السورة، رقم الآية، وزر استماع فوري أو فتح في المصحف.
   - في شريط التلاوة السفلي والمشغل المصغر (`GlobalMiniPlayer`): أيقونة **مؤقت النوم (🌙)** تعرض العد التنازلي النشط، وأيقونة **تكرار الآية (1× / 3× / 5× / ∞)** للحفظ.
3. **في قسم الأذكار ومواقيت الصلاة (Adhkar & Prayers)**:
   - إمكانية تفعيل مؤقت النوم أثناء الاستماع المتواصل للأذكار، ومشاركة أي ذكر أو حكمة صلاة كبطاقة مصورة.

### ب. الهوية البصرية والألوان
- **الألوان**: استمرار الهوية الليلية الفاخرة (`#0B0F12` و`#121820`) مع الذهبي الإسلامي (`#D4AF37`) والأخضر الزمردي (`#10B981`) والسماوي الهادئ (`#06B6D4`).
- **الخطوط**: خط المصحف العثماني (`Amiri Quran` / `Scheherazade New`) للآيات والأحاديث داخل البطاقات المصورة، مع أرقام متناسقة (`tabular-nums`) لمؤقت النوم وعداد التكرار.

## ٣. القرارات التقنية والمفاضلات (Product Decisions & Trade-Offs)

- **القرار ١: توليد البطاقات الدعوية المصورة عبر HTML5 Canvas بدقة 1080×1080 / 1080×1350**
  - *الأسلوب المختار*: رسم البطاقة مباشرة داخل المتصفح باستخدام `HTML5 Canvas 2D` مع تضمين الخلفيات الإسلامية والخطوط العربية والزخارف الذهبية، وتصديرها كملف `Blob / PNG` يدعم `navigator.share({ files })` أو التحميل المباشر.
  - *لماذا؟*: يعمل بسرعة فورية وبدون إنترنت (Offline-ready) وبأعلى دقة ممكنة للواتساب وإنستغرام دون الحاجة لخوادم خارجية.
- **القرار ٢: الخفض التدريجي للصوت (Smooth Audio Fade-Out) في `AudioService`**
  - *الأسلوب المختار*: دمج مؤقت النوم داخل `CentralAudioService` بحيث يراقب الثواني المتبقية؛ وفي آخر ٣٠ ثانية يقوم بخفض مستوى الصوت (`audioElement.volume`) تدريجياً من `1.0` إلى `0.0` بنعومة قبل إيقاف التشغيل وإعادة مستوى الصوت الافتراضي `1.0` للتشغيل القادم.
  - *لماذا؟*: يمنع الانقطاع المفاجئ للصوت الذي قد يوقظ المستخدم أثناء نومه.

## ٤. الهيكلة التقنية وتدفق البيانات (Technical Architecture)

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         الشاشة الرئيسية (HomeView)                      │
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ بطاقة موحدة أنيقة: (مؤقت النوم · بحث الآيات · بطاقة دعوية مصورة) │  │
│  └───────────┬─────────────────────────┬──────────────────────┬──────┘  │
└──────────────┼─────────────────────────┼──────────────────────┼─────────┘
               ▼                         ▼                      ▼
┌──────────────────────────┐ ┌──────────────────────┐ ┌───────────────────┐
│  CentralAudioService     │ │   QuranService       │ │ ShareCardModal    │
│  • مؤقت النوم الذكي      │ │  • بحث نصي في الآيات │ │ • معاينة البطاقة  │
│  • خفض تدريجي للصوت 30s  │ │    (محلي + API)      │ │ • 4 خلفيات إسلامية│
│  • تكرار الآية (1/3/5/∞) │ │  • انتقال فوري للآية │ │ • تصدير ومشاركة   │
│  • إيقاف عند نهاية السورة│ └──────────┬───────────┘ │   صورة PNG عالية  │
└──────────────┬───────────┘            │             └─────────┬─────────┘
               ▼                        ▼                       ▼
┌─────────────────────────────────────────────────────────────────────────┐
│       تكامل سلس مع أقسام: المصحف · المشغل المصغر · الأذكار · الصلوات    │
└─────────────────────────────────────────────────────────────────────────┘
```

### مكونات الحالة والتفاعل:
1. **حالة مؤقت النوم والتكرار في `CentralAudioService`**:
   - حفظ الوقت المتبقي بالثواني (`sleepTimerRemainingSeconds`)، وضع التوقف عند نهاية السورة (`stopAtEndOfSurah`)، وعدد مرات تكرار الآية للحفظ (`ayahRepeatTarget`: `1 | 3 | 5 | 10 | 0`).
   - بث التحديثات الفورية لجميع المشغلات (`GlobalMiniPlayer`, `QuranReaderView`, `AdhkarPlayerSheet`) لعرض العد التنازلي الحي.
2. **محرك البحث القرآني المزدوج في `QuranView` والنافذة السريعة**:
   - يدعم البحث بدون تشكيل (تطبيع الحروف العربية: أ/إ/آ -> ا، ة -> ه) للبحث السريع في السور المحفوظة محلياً وعبر واجهة المصحف الشريف.
3. **استوديو البطاقة الدعوية المصورة (`ShareCardModal`)**:
   - يستقبل النص (آية قرآنية، حديث شريف، أو ذكر) + المصدر + التفسير/البيان المختصر، ويتيح للمستخدم اختيار التصميم ومشاركته كصورة أو تنزيله بضغطة زر.
