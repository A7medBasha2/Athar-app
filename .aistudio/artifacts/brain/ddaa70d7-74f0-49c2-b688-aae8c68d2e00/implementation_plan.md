# محرك السكينة الفورية (Haptic Serenity Engine)

تطوير محرك اهتزاز وتفاعل لمسي فني (`Haptic Serenity Engine`) يربط جسد المستخدم بالذكر والتسبيح عبر نبضات خفيفة ومتناغمة تشبه نبضات القلب الهادئة عند كل تسبيحة أو ذكر، مع نبضة احتفالية مميزة عند إتمام الورد (33 أو 100)، ليعزز الخشوع ويفصل العقل عن المشتتات الخارجية فوراً.

## مراجعة اختيارات المستخدم والقرارات المعتمدة

> [!IMPORTANT]
> تم بناء هذه الخطة بناءً على اختياراتك المؤكدة:
> - **نمط الاهتزاز**: نبضة قلب هادئة ومزدوجة (`Lub-Dub`) عند كل تسبيحة أو ذكر، مع نبضة ختامية مميزة عند اكتمال الورد أو الدورة (33 أو 100 أو عدد الذكر المحدد).
> - **نطاق التفعيل**: يعمل في **المسبحة الإلكترونية الذكية**، و**أذكار الصباح والمساء**، و**أذكار ما بعد الصلاة المكتوبة (المعقبات)**.
> - **التحكم والتخصيص**: شريط/زر تحكم سريع ومباشر داخل شاشة التسبيح وشاشة الأذكار لتبديل التشغيل أو تغيير شدة ونمط النبض فوراً، بالإضافة إلى قسم متكامل في صفحة **الإعدادات** مع زر معاينة حية للنبضة.

---

## 1. النظرة العامة والقيمة الأساسية

- **ماذا يقدم المحرك؟**
  يحوّل عملية التسبيح وقراءة الأذكار من مجرد ضغط رقمي صامت إلى تجربة حسّية ولمسية هادئة؛ حيث يطلق الهاتف عند كل تسبيحة نبضة قلب خفيفة ومنتظمة (`[14ms, 65ms, 24ms]`) متزامنة مع موجة بصرية ذهبية ناعمة وطيف صوتي اختياري خافت بتردد دافئ يحاكي الإحساس اللمسي حتى على الأجهزة التي لا تدعم اهتزاز المتصفح.
- **الفئة المستهدفة وسياق الاستخدام:**
  الذاكرون في أوقات الصباح والمساء، وبعد الصلوات المكتوبة، وفي جلسات التسبيح الهادئة الذين يبحثون عن حضور القلب والتركيز الكامل بعيداً عن التشتت البصري.
- **القيمة المضافة:**
  ربط الحواس بالذكر دون الحاجة للنظر المستمر إلى الشاشة، بحيث يعرف المستخدم بلمسة يده أنه أتم تسبيحته أو وصل إلى ختام الورد (33 أو 100) عبر نبضة التمام المميزة.

---

## 2. تجربة المستخدم والتصميم البصري واللمسي

- **مسارات الاستخدام الرئيسية (User Flows):**
  1. **داخل المسبحة الإلكترونية (`DigitalTasbihModal`)**:
     - يظهر أعلى حلقة التسبيح شريط أنيق خاص بـ **«محرك السكينة الفورية»** يعرض حالة النبض (مفعّل / متوقف) مع مؤشر نبض حي واختيار سريع للشدة (`هادئ جداً` · `نبض متوازن` · `عميق`) والنمط (`نبضة القلب الهادئة` · `لمسة الحرير الخفيفة` · `إيقاع السكينة المتدرج`).
     - عند كل لمسة لحلقة التسبيح، ينبض المحرك بنبضة قلب مزدوجة خفيفة مع حلقة ضوئية ذهبية تتمدد بهدوء حول العداد.
     - عند الوصول إلى الهدف (33 أو 100 أو 1000)، يطلق المحرك **«نبضة تمام الورد»** الثلاثية المتناغمة.
  2. **داخل صفحة الأذكار (`AdhkarView`) وأذكار ما بعد الصلاة**:
     - إضافة تبويب رابع أصيل في شريط الأذكار العلوي بعنوان **«أذكار بعد الصلاة»** يضم أذكار دبر الصلوات المكتوبة الصحيحة (الاستغفار ثلاثاً، اللهم أنت السلام، لا إله إلا الله وحده، آية الكرسي، المعوذات، والتسبيح والتحميد والتكبير 33 مرة وتمام المائة).
     - إضافة **شريط التحكم السريع بمحرك السكينة الفورية** في أعلى قسم الأذكار لتمكين المستخدم من تفعيل/إيقاف النبض أو تعديل قوته بلمسة واحدة أثناء القراءة.
     - عند النقر على أي بطاقة ذكر أو عند انتقال القارئ الآلي (`AdhkarPlayerSheet`) من تكرار إلى آخر، ينبض الهاتف بنبضة السكينة، وعند اكتمال عدد الذكر ينبض بنبضة التمام المميزة.
  3. **داخل صفحة الإعدادات (`SettingsView`)**:
     - قسم مخصص بعنوان **«محرك السكينة الفورية (Haptic Serenity Engine)»** ضمن تبويب التنبيهات والكل، يتيح التحكم الشامل في التفعيل، اختيار نمط النبضة، مستوى الشدة، وتجربة النبضة مباشرة عبر زر **«معاينة نبضة السكينة»**.

- **الهوية البصرية والتناغم الحركي:**
  - *الاتجاه الفني*: الفخامة الملكية الهادئة بالأسود العميق والذهبي الدافئ (`#080705`, `#14120D`, `#C8A24A`, `#E6C66E`, `#F3E5AB`).
  - *التغذية البصرية المرافقة للنبض*: نبضة بصرية متزامنة (`transform: scale` و `opacity` خفيفة خلال 180ms) تحاكي اتساع نبضة القلب الذهبية حول دائرة العداد دون أي اهتزاز مزعج للنصوص.

## 3. القرارات الهندسية والبدائل التقنية

- **القرار 1: محرك اهتزاز هجين (Web Vibration API + Sub-Bass Tactile Pulse)**
  - *النهج المختار*: استخدام `navigator.vibrate` بأنماط مصممة بالملي ثانية (مثل `[12, 60, 22]` لنبضة القلب `Lub-Dub`) على هواتف أندرويد والمتصفحات الداعمة، مع توليد نبضة صوتية لمسية منخفضة التردد جداً (`65Hz–90Hz` عبر `Web Audio API` اختيارية) لتعطي إحساساً لمسياً دافئاً ومسموعاً بهمس خافت على الأجهزة التي تقيّد الـ Vibration API مثل iOS Safari.
  - *السبب*: ضمان شعور المستخدم بنبضة السكينة الفورية على جميع الهواتف والمتصفحات دون استثناء.
- **القرار 2: حفظ تفضيلات المحرك ومزامنتها الفورية**
  - *النهج المختار*: حفظ إعدادات المحرك في `localStorage` مع نظام اشتراك (`subscribe`) يربط بين شريط التحكم السريع في المسبحة، وشريط الأذكار، وصفحة الإعدادات في الوقت الفعلي.

## 4. البنية التقنية وتدفق البيانات

```
┌───────────────────────────────────────────────────────────────────────────┐
│                 HapticSerenityService (محرك السكينة الفورية)              │
│  • الأنماط: heartbeat (نبضة القلب) | silk (لمسة خفيفة) | deep (إيقاع عميق)│
│  • الشدة: soft (هادئ) | balanced (متوازن) | strong (واضح)                 │
│  • المخرجات: navigator.vibrate([...]) + WebAudio Tactile Sub-Pulse + UI   │
└───────────────┬─────────────────────────────┬─────────────────────────────┘
                │                             │
      ┌─────────▼──────────┐        ┌─────────▼──────────┐
      │ شريط التحكم السريع  │        │   صفحة الإعدادات   │
      │ HapticSerenityBar  │        │   SettingsView     │
      └─────────┬──────────┘        └────────────────────┘
                │
  ┌─────────────┼─────────────────────────────┐
  ▼             ▼                             ▼
┌────────────────────┐ ┌────────────────────┐ ┌────────────────────┐
│ المسبحة الإلكترونية │ │ أذكار الصباح والمساء│ │ أذكار ما بعد الصلاة│
│ DigitalTasbihModal │ │     AdhkarView     │ │ (المعقبات النبوية) │
└────────────────────┘ └────────────────────┘ └────────────────────┘
```

- **نموذج بيانات الإعدادات (`HapticSerenitySettings`)**:
  - `enabled`: تفعيل أو إيقاف المحرك (افتراضياً `true`).
  - `pattern`: نمط النبضة (`'heartbeat'` نبضة القلب المزدوجة | `'gentle_pulse'` نبضة مفردة ناعمة | `'ascending'` تدرج خاشع).
  - `intensity`: قوة النبضة (`'feather'` خفيفة جداً | `'balanced'` متوازنة | `'deep'` عميقة).
  - `milestoneCelebration`: تفعيل نبضة التمام المميزة عند إكمال 33 أو 100 أو انتهاء الذكر.
  - `tactileAudioResonance`: تفعيل الرنين اللمسي الخافت المساند لنبضة القلب.
