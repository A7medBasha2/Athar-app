# خطة التدقيق والتنفيذ: لوحة الملف الشخصي ونظام الإنجازات (أثر - Athar)

استناداً إلى الفحص المعماري الشامل لكود تطبيق **«أثر» (com.athar.islamic)** والمرجع البصري المرفق، يوضح هذا التقرير تفاصيل التدقيق (PHASE 1)، وخطة التنفيذ الهندسية الدقيقة (PHASE 2)، وضمانات الحماية الصارمة للميزات الحالية (PHASE 3).

---

## المرحلة الأولى: التدقيق الفني الشامل (PHASE 1 — PROJECT AUDIT)

### 1. البنية التحتية وإطار العمل ومنظومة التنقل
* **البيئة والمنظومة**: تطبيق هجين فائق الأداء مبني بـ React 18 + TypeScript + Vite مدمج مع **Capacitor 8** ويدعم أندرويد الأصيل (Android SDK 36, Min SDK 26) بمحرّك Kotlin أصيل وJetpack Media3 وHilt.
* **إدارة التنقل (`src/App.tsx`)**:
  - يعتمد نظام التنقل الحالي على `activeTab` من نوع `NavigationTab` ('home' | 'journey' | 'companion' | 'prayers' | 'quran' | 'adhkar' | 'stories' | 'explore' | 'qibla' | 'settings').
  - شريط التنقل السفلي (`src/components/BottomNav.tsx`) يعرض حالياً 8 تبويبات رئيسية، بينما تُعرض شاشة تسجيل الدخول (`AuthView.tsx`) والمودالات التفاعلية فوق الشاشة.
* **الهوية البصرية ونظام الألوان**:
  - الخلفية العميقة: `#080807` و `#0A0A0A`.
  - الأسطح المرتفعة: `#14120B` و `#1B170B` و `#161410`.
  - الذهب الأساسي والملكي: `#D9AE48` و `#C8A24A` و `#FFE6A0` و `#E6C66E`.
  - النصوص: رمادي دافئ `#B5AD9B`، وأبيض دافئ `#F7F2E7`.

### 2. حالة المصادقة وحسابات Firebase Auth
* **خدمات المصادقة الحالية (`AuthService.ts`)**:
  - يدعم البريد الإلكتروني وكلمة المرور (`createUserWithEmailAndPassword` و `signInWithEmailAndPassword`) مع فحص قوة كلمة المرور والتحقق بالبريد.
  - يدعم تسجيل الدخول بجوجل Google Sign-In عبر بلجن Capacitor الأصيل للأندرويد `@codetrix-studio/capacitor-google-auth` بمعرف العميل `702259871855-vb33jlkidsgiqift6uh5na7n24l5u4pg.apps.googleusercontent.com`.
  - يدعم «وضع الزائر (Guest Mode)» المحفوظ في `localStorage`.
* **بيانات المستخدم الحالية المتاحة**:
  - `uid`: المعرّف الفريد الثابت في Firebase Auth.
  - `displayName`: الاسم الظاهر للمستخدم.
  - `email`: البريد الإلكتروني للمستخدم.
  - `photoURL`: رابط الصورة الشخصية أو الأفاتار.
  - `metadata.creationTime`: تاريخ إنشاء الحساب الأصلي (لتحديد "عضو منذ ...").
  - `emailVerified`: حالة التحقق من البريد.

### 3. قاعدة البيانات Firestore وقواعد الأمان
* **قاعدة البيانات**: `ai-studio-atharapp-32312ff3-cfb7-4fbd-9f3d-5b70f4ef5f09`.
* **المخطط الحالي (`firebase-blueprint.json` و `firestore.rules`)**:
  - مجموعة `/users/{userId}` مع قواعد أمان محكمة ABAC تسمح للمستخدم المالك بقراءة وتحديث بياناته فقط (`isOwner(userId)`).
  - تحتاج إضافة حقول المظهر الجديد مثل: `username` (اسم المستخدم الفريد)، `bio`، `privacySettings`، `avatarPreset` أو رفع صورة الأفاتار الشخصية.

### 4. محركات تتبع الأنشطة والإحصائيات والبيانات الحقيقية
يمتلك التطبيق بنية تتبع بيانات محلية قوية جداً وحقيقية في `StorageService` و `ImpactTreeService` تشمل:
1. **الصلاة (`PrayerAchievementsState`)**: سجل الصلوات الخمس المؤداة اليومية، السنن، قيام الليل، وسلسلة الأيام (Streak).
2. **القرآن الكريم (`QuranKhatmahState`)**: صفحات/آيات القراءة، دقائق الاستماع للقرآن، تقدم الختمة الحالية.
3. **الأذكار (`AdhkarStats`)**: عداد التسبيحات التراكمي، إتمام أذكار الصباح والمساء، أطول سلسلة استمرار.
4. **الصدقات وأعمال الخير (`SadaqahRecord[]`)**: سجل مبادرات الإحسان والصدقات المسجلة ومواعيدها.
5. **شجرة الأثر ونقاط الخبرة (`ImpactTreeService`)**: محرك حساب معدل الالتزام (0-100%) ونقاط العمل الصالح والمستويات، مما يضمن **عدم تزييف أي بيانات أو اختراع نسب وهمية**.

## المرحلة الثانية: خطة التنفيذ المقترحة (PHASE 2 — IMPLEMENTATION PLAN)

سنقوم ببناء وتضمين لوحة الملف الشخصي المتطابقة تماماً مع تصميم المرجع الملكي المرفق:

### 1. واجهة شاشة الملف الشخصي الرئيسية (`src/views/ProfileDashboardView.tsx`)
* **الترويسة (Header)**:
  - شعار أثر الملكي الذهبي المعتمد مع عنوان «الملف الشخصي».
  - زر الإعدادات التفاعلي السريع ⚙️ في الزاوية المقابلة للانتقال الفوري إلى إعدادات التطبيق.
* **بطاقة الهوية الشخصية (Profile Identity Card)**:
  - إطار هندسي إسلامي مقوّس (Mihrab-inspired Arch) بخلفية متدرجة سوداء وذهبية فاخرة.
  - صورة الأفاتار الدائرية مع زر الكاميرا الصغير الذهبي لتغيير الصورة أو اختيار أفاتار إسلامي أنيق.
  - الاسم الظاهر بخط عربي عريض وواضح (`أحمد محمد`).
  - معرّف الحساب المسبوق بـ `@` (مثل `@ahmed`).
  - تاريخ الانضمام الدقيق المستخرج من بيانات الحساب: «عضو منذ 12 مارس 2025 📅».
  - زر تعديل الملف الشخصي (Edit Profile Action).
* **شريط اكتمال الملف الشخصي (Profile Completion Card)**:
  - شريط تقدم ديناميكي متدرج بالذهب الخالص محسوب رياضياً بناءً على الحقول المكتملة فعلياً:
    *(الاسم + اسم المستخدم + البريد المؤكد + الصورة/الأفاتار + النية/الوصف)*.
  - عرض النسبة المئوية الدقيقة (مثل `75%`) مع تنبيه ذكي بالحقول المتبقية (دون تزييف أي نسبة).
* **لوحة المستوى ونقاط الخبرة (Level & XP Summary)**:
  - بطاقة أفقية منقسمة بأناقة:
    - الجانب الأيمن: شارة XP الذهبية مع مجموع نقاط الخير المكتسبة من الطاعات (مثل `1,250 XP`).
    - الجانب الأيسر: شارة النجمة الذهبية المحاطة بإكليل مع رقم المستوى الحالي (مثل `المستوى 6`) وشريط تقدم نحو المستوى القادم.
* **بطاقة الاستمرارية والالتزام (Streak Card)**:
  - أيقونة الشعلة المتوهجة الذهبية 🔥.
  - عدد أيام الاستمرارية المتتالية (مثل `12 يوماً متتالياً`).
  - العبارة التحفيزية الراقية: «الاستمرارية تصنع الفرق .. 🌱».
* **شبكة الإحصائيات (إحصائياتك - Statistics Grid)**:
  - شبكة من 4 كروت مربعة أنيقة بأيقونات ذهبية مخصصة وأسهم تفاعلية:
    1. **القرآن 📖**: ساعات الاستماع وصفحات التلاوة لهذا الشهر.
    2. **الصدقات 💛**: عدد نشاطات الإحسان والصدقات لهذا الشهر.
    3. **الأذكار 📿**: مرات التسبيح وحصن المسلم لهذا الشهر.
    4. **الصلاة 🕌**: عدد الصلوات المفروضة المسجلة لهذا الشهر.
* **بانر رحلتك مع أثر (Journey Banner)**:
  - خلفية بانورامية ليلية مع أفق المساجد والمنارات والهلال الذهبي المتلألئ.
  - عنوان: «رحلتك مع أثر ›» مع النص التحفيزي: «خطوات صغيرة .. أثر كبير».
  - ينقر عليه لفتح تفاصيل الإنجازات والرحلة التراكمية.

### 2. شاشة / نافذة تعديل الملف الشخصي وصورة الحساب (`ProfileEditModal.tsx`)
- تعديل الاسم الظاهر واسم المستخدم (@handle) مع فحص الصياغة.
- اختيار صورة من المعرض أو التقاطها، بالإضافة إلى مجموعة أفاتارات إسلامية ملكية جاهزة خفيفة الوزن.
- إعدادات الخصوصية (إظهار/إخفاء الإحصائيات في المشاركة، حفظ البيانات محلياً أو سحابياً).

### 3. تكامل Firebase وFirestore
- تحديث `firebase-blueprint.json` لإضافة الحقول الجديدة (`username`, `level`, `xp`, `bio`).
- تحديث وتدقيق `firestore.rules` لحماية هذه الحقول مع منع التعديل الذاتي للحقول الحساسة وضمان عدم تسريب البيانات.
- نشر القواعد وفحصها أمنياً.

### 4. دمج شريط التنقل السفلي وإمكانية الوصول
- إضافة التبويب إلى التنقل السلس، وإمكانية الوصول إليه من زر الحساب في الإعدادات أو القائمة السفلية مع الحفاظ التام على كامل تبويبات التطبيق دون كسر أي شاشة.

## المرحلة الثالثة: حماية الميزات الحالية (PHASE 3 — PROTECTIONS)

نؤكد الالتزام التام بالقواعد الصارمة:
1. **عدم كسر المصادقة**: الحفاظ على تسجيل الدخول بالبريد وجوجل ووضع الزائر والـ Sessions الحالية.
2. **الحفاظ على معرّف التطبيق**: سيبقى ثابتاً `com.athar.islamic` في كافة ملفات Gradle وManifest.
3. **عدم اختراع أو تزييف البيانات**: جميع إحصائيات القرآن، الأذكار، الصلوات، وأيام الاستمرار تُستخرج مباشرة من محرك `StorageService` و `ImpactTreeService`.
4. **عدم حذف أو تعديل أي شاشة شغالة**: جميع شاشات القبلة، القرآن، الأذكار، القصص، وإعدادات الأذان تعمل بكامل طاقتها دون مساس.
